The conversion formula for a temperature that is expressed on the Celsius (°C) scale to its Fahrenheit (°F) formula is given below:

°F = (9/5 × °C) + 32.

Java Code :-

class Solution
{
public double cToF(int C)
{
int Fahrenheit = (C*9/5)+32;
return Fahrenheit;
}
